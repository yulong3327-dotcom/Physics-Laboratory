# 物理仿真AI实验室

面向物理实验搭建的 React + TypeScript 工作台，提供独立的电学、光学与回声测距实验室。电学画布使用 React Flow，提供 13 种电路符号、17 个实物外观、元件拖放、端点连线、直流稳态实验及工程、图片和视频导出。

## 回声测距实验室

点击顶部“回声测距”或访问 `/#echo`，输入题目后匹配物理模型、提取题设参数并生成可调节、可播放的仿真。默认使用 `deepseek-v4-pro-zy` 解析，连接或条件校验失败时回退本地规则；也可选择完全离线的本地模式。直接打开此工作区和使用本地模式无需 SK，登录弹窗也提供直接入口。

题目复制过程中丢失的数字、图片和图表不会被编造；缺失参数需要补全，示例参数仅用于演示。可以逐步积累带模型标签的训练样本，扩充本地匹配能力。使用方法和模型范围见 [回声测距实验室说明](docs/echo-laboratory.md)。

## 光学实验室

点击顶部“光学实验室”或访问 `/#optics`，即可进入独立的几何光学工作台。支持凸透镜、凹透镜、平面镜、平行光源、点光源、激光笔、物体箭头、光屏、光阑、平行玻璃板和三棱镜，共 11 类基础组件。组件采用 SVG 二维教材风格，物体、实像和光线方向箭头采用纯蓝色实心矩形杆与三角头，虚像以蓝色虚线轮廓区分，画布保留浅色背景与网格。

支持拖放、光轴水平/垂直切换与任意旋转、焦距/口径/折射率调节、实时光线追迹、焦点与虚光线，以及多片同轴透镜的中间像、最终像和累计放大率测量。内置 10 个实验预设，显微镜与望远镜均由可独立编辑的普通凸透镜和光源组成。支持暂停、缩放平移、撤销重做及 JSON 导入导出；光学与电学草稿分别保存，旧显微镜、望远镜草稿自动转换为透镜与光阑组合。使用方法、模型范围和组件扩展方式见 [光学实验室说明](docs/optics-laboratory.md)。

## 启动

建议使用 Node.js 24（与 Vibe Hub 部署环境一致）。在本目录执行：

```sh
npm install
npm run dev
```

打开终端输出的本地地址。AI 接口配置见 [AI 接入说明](docs/ai-setup.md)，手动画布功能不依赖 AI 服务。

电学、光学和视频工作区首次访问先显示连接登录弹窗，填写自己的 SK。回声测距工作区 `/#echo` 可直接使用。默认地址为 `https://ccproxy.yukework.com`，普通模型为 `gpt-6-astra`，图片模型配置为 `gpt-image-2`。视频项目中心入口为 `/#video`。

所有模型提示词已独立到 [prompts/](prompts/README.md)，按能力维护 Markdown 正文，版本和变量见 `prompts/manifest.json`。修改后运行 `npm run prompts:generate`；开发启动、测试和构建也会自动生成并校验提示词目录。

本机作为局域网服务器时，双击 `启动局域网服务.cmd`，把生成的 `局域网访问地址.txt` 中链接发给同一网络的访问者；双击 `停止局域网服务.cmd` 关闭后台服务。配置、工程分享与使用说明见 [本机局域网运行](docs/local-server.md)。

## 部署到 Vibe Hub

执行 `npm run package:vibehub`，将生成的 `release/circuit-converter-vibehub.zip` 上传到平台，工具类型选择 **H5 Node**。压缩包包含构建产物和源码，不包含本机密钥。具体步骤见 [Vibe Hub 部署说明](docs/vibehub-deployment.md)。

本地修改不会自动发布到网站；重新打包后，在同一工具的版本管理上传新版。访问网站的电脑浏览器刷新后使用新版。本机与网站草稿互相隔离，迁移时使用 JSON 导出/导入。

## 编辑电路

- 从元件库拖入画布；触屏上可点选元件，再点画布放置。
- 切换“实物图”可使用导入的透明 PNG 素材；切回“电路图”保留元件及端口连接。两种视图的位置、朝向和手动导线路径分别保存，移动或整理一边不会改变另一边的摆放。实物默认保持原图的统一朝向。属性面板可切换外观，支持撤销。
- 在选择模式拖动元件，从接线柱拖到另一个接线柱建立导线；连线模式也支持依次点击两个接线柱。同一端点及重复导线会被拒绝。
- 选中元件后修改标签或旋转方向；选中元件、导线后均可删除。删除元件会同步移除它的导线。
- 选择模式下点选导线，拖动方形控制点：电路图调整水平或垂直线段，实物图调整线缆弯曲。接线柱位置和电气连接保持不变。一次拖动为一步撤销，Escape 取消；属性面板“恢复自动走线”只重置当前视图的该导线。
- 使用平移工具移动视野，使用滚轮或画布右下角按钮缩放。支持网格吸附、适应画布、撤销和重做。
- AI 导入会分别整理两种视图，保留接线拓扑；工具栏“自动整理”只重排当前视图，并重置当前视图的手动走线，支持撤销。常见电路按矩形主回路、并联支路和测量关系排列；实物图按实验台分行放置并保持仪表正向。复杂网络使用 ELK，无法求得布局时使用间隔网格，任意拓扑仍可能需要人工微调。
- 电路图使用深灰细线、90 度直角导线及矩形电阻，自动走线优先少拐点的矩形路径；实物图相邻相向接线柱优先直线或浅 S 弯，转弯线缆保持自然曲线和高光。两种视图的端点随各自元件移动、旋转和外观切换更新。
- A/V 在电路图中无论接低量程还是高量程都显示两端符号，实物图保持三柱，原端口 ID 不变。未接正端时可通过“接线量程”选择要连接的端子；已接正端时锁定选择。三个端子都接线时保留三端和异常诊断。
- 工具栏支持载入示例、清空画布和导入 JSON；导出包含 JSON、SVG、PNG、Manim 工程包、MP4 和 WebM。JSON 导入上限为 2 MB，并检查元件类型、坐标、参数、标识和连接端点。
- 编辑结果自动保存为当前浏览器、当前站点的本地草稿，刷新后恢复。不同端口、浏览器和设备不共享草稿；重要版本请导出 JSON。撤销历史在刷新后重置。

| 快捷键 | 操作 |
| --- | --- |
| `V` / `W` / `H` | 选择 / 连线 / 平移 |
| `R` | 旋转选中元件 |
| `Delete` / `Backspace` | 删除选中元件或导线 |
| `Escape` | 取消当前拖动、放置或连线，并清除选中 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` / `Ctrl/Cmd + Y` | 重做 |

输入框和 AI 弹窗内不会触发画布快捷键。

## 实验与导出

接线后点击“实验”，可查看通电、开路、短路等状态及元件电流、电压和功率。修改电源电压、内阻、电阻阻值、灯泡额定参数，或调节变阻器滑片，会重新计算当前直流工作点。灯泡随功率点亮，电流表、电压表的指针支持自动测量与手动设针。手动读数仅改变展示，不改变电路计算。

实物开关使用固定底座和转动刀片，灯泡使用固定底图和局部发光层，状态变化保持宽高比、底座和接线柱位置。通电导线上显示黄色小点，按每条支路的常规电流方向移动；单电源外部回路通常从正极经过负载流向负极。粒子速度仅为示意，不代表电子速度；小于 10 µA 的电流不显示黄点。冗余理想导线环采用满足节点电流守恒的等权最小范数分流，不模拟真实线缆电阻。

点击“录制实验”，可记录实际开关、调阻与实验启停过程，再选择“已录制的实验过程”导出。单次最长 60 秒、最多 1500 条状态记录（含初始状态），仅在当前页面暂存，刷新即丢失，普通工程 JSON 不包含录制。录制快照不重复携带 AI 参考原图，原工程中的参考图保持不变。视频与 Manim 按 24 fps 重放原始时间和参数变化，包含开关、灯泡、表针和移动电流点。

| 格式 | 内容与前提 |
| --- | --- |
| JSON | `schemaVersion: 2` 工程，保留拓扑、参数、两种位置和朝向、各视图手动路线、素材 ID 和当前视图，可重新导入编辑器。 |
| SVG / PNG | 当前电路的独立图片；SVG 内嵌实物 PNG，无需访问本地素材服务器。PNG 为 1280 x 720。 |
| Manim ZIP | `scene.py`、`project.json`、`circuit.svg`、`timeline.json` 及每帧 PNG；在已有 Python、Manim Community 和 FFmpeg 的环境执行 `manim -qm --fps 24 scene.py CircuitExperiment`。 |
| MP4 / WebM | 浏览器直接编码 1280 x 720、24 fps 视频；录制保持原时长（0.25 至 60 秒），预设可选 2 至 30 秒。HTTPS 或 localhost 优先使用 WebCodecs，MP4 需要 H.264，WebM 需要 VP9 编码支持。HTTP 网站在浏览器支持时使用 MediaRecorder 实时录制画布，MP4 需要其 H.264 支持，WebM 可使用 VP9 或 VP8。 |

动画可选择已录制过程、当前电路电流动画、开关由断开到闭合、滑片从 A 端到 B 端。Manim 的 `timeline.json` 保留录制事件与时间戳，场景按预计算图片帧播放，未将每个元件转换为可编辑的 Manim 对象，也不在 Python 中重新求解电路。本机尚未实际运行 Manim 渲染。视频不含音频；编码器不可用时导出会提示选择其他格式。

MediaRecorder 兼容导出约需视频本身的时长，导出期间请保持页面在前台。它仅录制应用生成的画布，不调用摄像头或麦克风；视频生成及数据处理均在当前浏览器内完成。

接线示例、仪表量程、模型假设和导出说明见 [实验与导出说明](docs/experiment.md)。

## 验证

```sh
npm run build
npm test
npm run test:e2e
```

构建产物输出到 `dist/`。单元测试覆盖数据校验、编辑历史、符号几何、电学计算、导线电流守恒、录制事件与实验预设；端到端测试验证浏览器画布与导出交互。首次运行端到端测试若缺少 Chromium，可执行 `npx playwright install chromium --no-shell` 后重试。默认 AI 测试使用模拟响应；真实接口测试需要显式设置 `LIVE_AI=1`。

完整参考图识别回归使用 `LIVE_AI_REFERENCE=1`，样本保存在 `e2e/fixtures/`，每张图片会调用两次已配置的模型。2026-09-08 已通过 `gpt-5.5` 实际验收：四元件串联电路图及六元件实物图的接线节点均匹配参考图。图片结果存在待确认项时会显示警告；这些样例通过不代表任意图片识别都准确。

## 当前范围

已接入用户提供的实物元件图片：20 张原图归档、17 张透明展示图，另有用于动态实验的固定底图和局部图层。新增单节电池座、直流电源、旋钮电位器和两脚蜂鸣器。旧裸灯泡原图保留归档，灯泡 ID 和左右连线保持兼容。电压表、电流表的数据与实物图保留三个量程端子，电路图按实际接线投影为两端；滑动变阻器保留四个端子。旧文件中的双端电表和三端滑动变阻器会补齐新端口，原有连接 ID 保持不变。

裸电机图片未显示电气端子，其接点用虚线标为示意位置；电铃尚无对应实物素材，在实物图中保留符号。电位器引脚分配为实验示意，蜂鸣器类型及极性无法由图片确认。来源、裁剪范围和识别说明见 [实物素材清单](docs/physical-assets.md)，接点坐标在 `src/data/physicalAssets.ts`。

仿真采用线性直流稳态模型，包含电源及仪表有限内阻。灯泡以额定参数得到的恒定电阻计算；电机、电铃、蜂鸣器按等效电阻负载计算。交流、温升、烧毁过程、机械运动、声音及瞬态响应未建模；灵敏电流计目前更新数值，实物蓝色表针仍为原图。AI 识别结果需要人工复核，应用后可继续编辑。

## 视频制作工作台

生产中心入口为 `/#video/production`：人工审核讲稿与分镜后，按已确认版本批量入队，后台持续制作；集中查看多项目进度、失败恢复和成片库。批量提交可在断网后用原记录重试，避免重复制作。使用与运行边界见 [视频生产平台](docs/video-production-platform.md)。

新增“视频制作”入口：导入完整讲稿、审核分镜、电路与公式、确认版本、生成双人配音和 Manim 视频，支持按镜头重做、任务取消及工程保存。内置《电功率：三个公式，两个比例》保留原稿 29 段旁白，分为 12 个镜头；视频工程与原有电路工程分别保存。

本地运行需要 Python、Manim、FFmpeg 和公式渲染工具。新建项目、内置课程与目标效果示范默认使用 Fish.audio s1 的方大招／金天练正式角色音色，需在服务端配置 Fish。已明确选择 Edge 或 Azure 的工程保留选择；服务不可用时不会自动切到免费音色。安装、使用、模型边界与验证方法见 [视频制作工作台](docs/video-workbench.md)。

“目标效果示范”提供通路/断路、灯泡旁路、串联分压及选择题四个可编辑镜头。现支持元件状态切换、图上电压/电流标注、保留多行推导、板书入场及动作时长设置。参考视频拆解、能力差距、验证结果与剩余规划见 [目标视频对照与生产能力补齐](docs/reference-video-gap-analysis.md)。
