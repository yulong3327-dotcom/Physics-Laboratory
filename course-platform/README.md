# 知课 · 微信课程小程序

生产部署步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。

一套可本地运行的课程销售与学习系统，包含原生微信小程序、学生网页预览、网页管理后台和 Node.js 服务端。界面参考所提供的课程截图，采用浅灰背景、白色圆角卡片和橙色主色。

学生正式使用以原生微信小程序为主：登录页默认微信认证，手机号验证码作为备用；学生网页保留为浏览器端入口，课程管理通过网页后台完成。

## 本地启动

安装 Node.js **24 或更新版本**，在本目录执行：

```powershell
npm install
npm run build
npm start
```

- 学生端：http://127.0.0.1:4310
- 管理后台：http://127.0.0.1:4310/admin
- 本地演示管理员：`admin` / `admin123456`
- 学生点击“登录 / 注册”，可演示登录，也可使用演示短信验证码登录。

双击根目录 `启动演示.cmd` 也可完成首次依赖安装、构建与启动。关闭服务终端会停止服务；重新启动后，课程、文件、订单和学习进度保留。

开发前后端同时运行：`npm run dev`，网页地址为 http://127.0.0.1:5173 ，接口仍为 4310。运行验证：`npm test`。

## 已实现功能

| 学生端 | 管理后台 |
| --- | --- |
| 微信 code 登录、微信手机号授权、手机号验证码登录 | 管理员独立登录与权限控制 |
| 搜索、科目和年级筛选、课程详情、免费试看 | 新建/编辑课程、定价、草稿、上下架、归档 |

本地演示模式预置 6 门**演示课程**和中文演示讲义；生产环境新建空课程库，不会把演示内容带给学生。视频演示使用公开的花朵素材，实际授课内容通过后台上传。每个演示新学生会自动加入免费多科体验课。演示购买不会扣款，开发短信不会向手机发送信息。

## 导入微信开发者工具

1. 可直接在微信开发者工具中导入本项目根目录，根 `project.config.json` 已设置 `miniprogramRoot` 指向 `miniprogram/`，并保留你在工具中填写的 AppID。开发语言选择 JavaScript，无需 npm 构建。
2. 也可单独导入 `miniprogram` 文件夹；其中配置已与根目录当前 AppID 保持一致。真实微信能力仍需该小程序账号已开通相应能力。
3. 本机服务保持运行。`miniprogram/app.js` 的 `apiBaseUrl` 默认为 `http://127.0.0.1:4310`，供本机工具调试。工具本地调试需允许未配置的开发域名；正式版本使用合法 HTTPS 域名。
4. 真机无法访问电脑的 `127.0.0.1`，真机联调应使用可访问的测试 HTTPS 服务，并配置 request、downloadFile、uploadFile 域名。
5. 演示账号和演示付款只在服务端 `DEMO_MODE=true` 时显示。真实微信认证使用 `wx.login`，微信支付使用 `wx.requestPayment`。

已通过微信自带 WCC/WCSC 的全部模板、样式编译检查。当前开发者工具模拟器运行检查超时，完整交互及真机流程仍需验收；未执行真实短信发送或真实扣款。本机真实微信登录配置见 [小程序说明](miniprogram/README.md)。

## 接入真实微信、短信和支付

复制根 `.env.example` 为根 `.env`，在本地填写凭据，**不要提交 `.env`、私钥或 API 密钥**。

```powershell
Copy-Item .env.example .env
```

正式环境设置 `NODE_ENV=production`、`DEMO_MODE=false`，并设置独立管理员密码（至少 12 位）与随机 `SESSION_SECRET`（至少 32 位）。生产启动拒绝默认管理员密码和演示功能。

- 微信登录：`WECHAT_APP_ID`、`WECHAT_APP_SECRET`。AppID 必须与小程序项目一致，密钥只存服务端。
- 手机号授权：使用微信提供的手机号授权 code；手机号验证码登录是另一条路径，两者均已实现。手机号账号购买前会引导关联同一手机号的微信身份以获取支付所需 openid；后台绑定接口保留当前账号及课程，拒绝不同手机号和身份冲突。
- 短信：默认使用腾讯云短信 SDK；配置 `TENCENT_SMS_SECRET_ID`、`TENCENT_SMS_SECRET_KEY`、`TENCENT_SMS_APP_ID`、已审核的 `TENCENT_SMS_SIGN_NAME` 和验证码 `TENCENT_SMS_TEMPLATE_ID`。也可显式设置 `SMS_PROVIDER=http` 使用兼容 HTTP 适配服务。
- 微信支付：配置商户号、商户证书序列号、商户私钥路径、API V3 密钥、微信平台证书/公钥路径及序列号、支付通知 URL。通知 URL 为 `https://你的域名/api/payments/wechat/notify`。平台证书轮换后同步更新配置。

系统按后端价格生成订单；仅在微信回调验签、解密并校验商户、AppID、交易类型、币种和金额后开通课程。JSAPI 还校验付款人 openid，Native 扫码付款使用回调中的付款身份。前端支付成功提示不会直接授课。网页学生端提供微信 Native 扫码支付，小程序端使用微信 JSAPI 支付。

## 部署与数据

服务默认监听 `4310`，通过 Nginx/Caddy 等配置 HTTPS 反向代理。设置微信平台服务器域名、业务类目、隐私声明与对应服务权限后再提交审核。生产公网服务应限制管理后台的访问来源，并使用独立密码。

- 数据库：`server/data/courses.sqlite`（SQLite，持久化）。
- 视频与讲义：`server/data/uploads`；单文件最大 250 MB，视频较大时可使用你有访问控制的 HTTPS 视频地址。
- 上传视频通过有时效签名地址播放；讲义要求登录且已选课。签名 URL 在有效期内持有者可访问，当前未提供 DRM 或离线缓存保护。
- 备份时停止服务，整体复制 `server/data`；数据库和文件必须一并保存。自定义路径通过 `DATABASE_PATH` / `UPLOAD_DIR` 设置。
- 课程下架/归档后从公开目录移除、停止新购；已购学员仍可在“我的课程”学习和下载。归档保留历史订单。

这是课程销售与录播学习的首个完整版本。直播、作业测验、排行榜、退款/售后、优惠券、多管理员和消息推送不包含在当前版本中，参考图中的测验/排行榜未做无效入口。

## 目录

```text
miniprogram/        原生微信小程序
web/src/student/   学生网页预览
web/src/admin/     课程管理后台
web/src/shared/    网页会话与请求封装
server/            API、SQLite、微信适配与集成测试
scripts/           本地启动脚本
```

`npm test` 验证学生登录/订单/权限/下载/进度持久化、后台课程和文件管理、生产模式保护、微信支付通知校验与幂等处理，以及小程序切课、进度与付款的异步流程。`npm run build` 检查网页生产构建。Windows 本机安装微信开发者工具后，可运行 `npm run check:miniprogram:compile` 重复 WCC/WCSC 编译检查；自定义安装位置使用 `WECHAT_DEVTOOLS_PATH`。正式微信平台联调不属于这些本地检查的覆盖范围。
