# 知课微信小程序

原生微信小程序是学生端的主要使用入口，登录页默认使用微信认证，手机号验证码登录作为备用。学生网页保留，教师通过网页管理后台上传和管理课程、视频及讲义。

小程序本身无需 npm 构建，包含发现课程、我的课程、个人中心、登录、课程详情、订单确认、视频学习、课程资料、我的订单和文本讲义预览共 10 个页面。视觉采用浅灰底、白色圆角卡片和橙色主色。

## 导入与后端地址

1. 安装 Node.js 24 或更新版本。在项目根目录执行 `npm ci`、`npm run build`、`npm start`。后端默认地址为 `http://127.0.0.1:4310`，课程管理后台为 `http://127.0.0.1:4310/admin`。`npm run build` 构建的是网页与管理后台，小程序无需此构建步骤。
2. 在微信开发者工具选择「导入项目」，目录选择项目根目录。根 `project.config.json` 已将 `miniprogramRoot` 设为 `miniprogram/`。也可以单独导入 `miniprogram` 文件夹；两处配置使用同一个 AppID：`wx949b46069f25443e`。保留此 AppID，开发语言选择 JavaScript，无需构建 npm。
3. `miniprogram/app.js` 中 `globalData.apiBaseUrl` 默认使用线上后端 `https://course.yulongchemistry.cn`，无需启动本机后端。保持开发者工具的合法域名、TLS 与 HTTPS 证书校验开启，并在当前 AppID 的微信后台配置 request、downloadFile 合法域名。
4. 在个人中心打开登录页，默认入口为「微信认证登录」。真实登录需要下文的服务端配置及当前微信账号具有该 AppID 的开发权限。没有配置凭据时，页面会提示能力未配置，不会把演示身份当成真实微信身份。
5. 如需本机调试，可临时把 `apiBaseUrl` 改为 `http://127.0.0.1:4310`，按第 1 步启动本机后端，并仅在开发者工具「详情 → 本地设置」中勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。手机上的 `127.0.0.1` 指手机自身；真机联调及发布前须恢复线上 HTTPS 地址、开启校验并重新编译。

后端未配置 `.env` 时默认使用演示模式，可查看演示课程与资料。演示登录、演示短信和模拟支付均有明确标识；这些入口不会发送真实短信或产生扣款。微信认证入口在配置凭据后仍调用真实微信服务。

## 本地配置真实微信登录

在项目根目录创建 `.env`，可从根 `.env.example` 复制；已有 `.env` 时直接编辑，避免覆盖原配置。凭据只在本机填写，不需要发送到聊天中。

- `WECHAT_APP_ID`：填写 `wx949b46069f25443e`，与开发者工具项目一致。
- `WECHAT_APP_SECRET`：在微信公众平台取得后填写到根 `.env`，只供后端使用。
- 若只测试真实登录，可保留本地演示模式；点击「微信认证登录」仍会真实验证微信身份，但演示短信和模拟付款仍然是演示功能。
- 若要关闭全部演示入口，将 `DEMO_MODE=false`，同时设置至少 12 位的独立 `ADMIN_PASSWORD` 和至少 32 位随机 `SESSION_SECRET`；默认密码和占位值会被后端拒绝。非演示模式的新数据库不自动添加课程，需通过管理后台上传。

修改 `.env` 后重启 `npm start`。从项目根目录启动即可；服务端入口固定读取根 `.env`，数据库、上传目录及证书相对路径也统一按项目根目录解析。

配置后先运行 `npm run check:wechat` 检查本地填写情况，再运行 `npm run check:wechat -- --verify` 向微信验证 AppID/AppSecret。检查命令不会显示密钥或微信 access_token。若微信返回 IP 白名单错误，按提示将后端出口 IP 添加至公众平台「开发管理 → 开发设置 → IP 白名单」。凭据验证通过后，再在小程序登录页勾选同意并点击「微信认证登录」，检查重新打开小程序后的登录保持、退出登录及再次登录。

`wx.login` 获取的是微信身份凭证，不能直接读取真实姓名、头像或手机号；手机号仍需学生点击微信手机号授权按钮，昵称可由学生在个人中心修改。首次登录后服务端自动创建账号，同一微信再次登录会找回同一账号与课程。

真实认证流程为：学生点击按钮后执行 `wx.login`，小程序将临时 code 发给 `/api/auth/wechat`，后端使用 AppID 与 AppSecret 向微信交换 openid，再签发本系统的登录令牌。AppSecret 不下发到小程序。不要把 `.env`、AppSecret、商户私钥或短信密钥提交到 GitHub，也不要写入小程序源码。

## 功能接入说明

- 微信手机号能力通过个人中心 `getPhoneNumber` 按钮授权，将 `phoneCode` 与新的 `wx.login` code 交给后端；需账号具备微信手机号能力，且真实登录能力已配置。后端会按微信身份/手机号匹配账号并拒绝冲突。演示账号不模拟绑定成功。
- 手机号验证码登录调用发送验证码与登录接口；真实发送使用腾讯云短信，需在根 `.env` 中配置已审核的短信应用、签名、模板和凭据。演示服务只展示演示验证码，并明确提示未发送真实短信。
- 购买创建服务端订单，正式环境调用 `wx.requestPayment`。客户端成功回调后仍查询服务端订单确认支付结果，未确认时提示刷新；订单列表支持继续支付。生产后端需配置微信支付与回调，且付款账号需拥有对应微信身份。
- 学习页使用后端校验权限后生成的视频地址，约每 10 秒、暂停、离开时上报进度。视频自然结束标记课时完成。后台上传正式视频前，种子课程可能使用明确标注的演示视频。
- 讲义通过带 `Authorization: Bearer` 的 `wx.downloadFile` 下载，Office/PDF 用 `wx.openDocument` 预览，并打开菜单用于保存。TXT/Markdown 打开本地文本预览，支持选择与复制全文。其他格式保存到小程序本地文件空间，不能保证设备可预览。每次下载仍由后端核验购买权限。

小程序默认已连接线上 HTTPS 服务。真机和正式发布前，在当前 AppID 的微信后台配置 request、downloadFile 合法域名 `https://course.yulongchemistry.cn`；学生端当前不上传文件，如增加上传功能再配置 uploadFile 域名。外部视频域名也需要满足微信相应要求。正式发布保持域名及证书校验开启。

## 验证范围

已通过 JSON、JavaScript 语法及页面引用静态检查，并通过微信开发者工具随附的 WCC（WXML）与 WCSC（WXSS）编译器的模板、样式编译检查。

在根目录运行 `npm test` 可重复后端与小程序异步回归检查；Windows 安装微信开发者工具后，运行 `npm run check:miniprogram:compile` 可重复真实模板与样式编译。工具装在自定义目录时，先将 `WECHAT_DEVTOOLS_PATH` 环境变量设为工具安装目录。

已在本机微信开发者工具中完成真实微信登录联调：官方接口验证 AppID/AppSecret，`wx.login` 获取有效 code，后端换取真实身份并创建学生账号，登录页面代码成功跳转至个人中心，系统令牌与用户信息保存到本地；从存储恢复后可访问鉴权接口，退出后旧令牌被拒绝，再次登录仍找到同一学生账号。检查脚本不输出 code、OpenID、令牌或密钥。

上述登录验证使用此前的本机后端与开发者工具 SDK 调用真实页面逻辑，页面元素点击自动化仍有超时，未完成全部交互的视觉验收。线上 HTTPS 后端已通过健康检查，当前 AppID 的线上微信登录、真机预览、微信手机号授权、腾讯云短信投递及真实支付回调仍需分别联调。
