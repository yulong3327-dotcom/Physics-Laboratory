# 知课微信小程序

原生微信小程序，无需 npm 构建。页面包括发现课程、我的课程、个人中心、微信/手机登录、课程详情、订单确认、视频学习、课程资料、我的订单和文本讲义预览。视觉采用浅灰底、白色圆角卡片和橙色主色。

## 本地启动

1. 按项目根目录说明启动后端服务，默认端口为 `4310`。
2. 微信开发者工具导入本目录，测试 AppID 默认为 `touristappid`。在 `app.js` 修改 `globalData.apiBaseUrl`。
3. 本地使用 `http://127.0.0.1:4310` 时，只在开发者工具中开启「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。正式发布保持校验开启。
4. 手机预览时，`127.0.0.1` 指手机自身，需改为手机能访问的开发机地址，或已配置的 HTTPS 测试服务地址。
5. 首次进入发现课程，可在个人中心选择登录。后端启用演示模式时，登录页明确提供「演示登录」，订单页为「模拟支付」，不发生真实授权、短信发送或扣款。

## 正式接入

- 将 `project.config.json` 中的 `appid` 改为真实小程序 AppID；后端使用相同 AppID 与 AppSecret。微信认证通过 `wx.login` 的临时 code，由后端向微信交换身份。
- 小程序后台配置 HTTPS `request`、`downloadFile` 域名；视频托管域名也应加入相关合法域名。修改 `apiBaseUrl` 为正式 HTTPS 服务。不要把 AppSecret、商户密钥、短信服务密钥写入小程序。
- 微信手机号能力通过个人中心 `getPhoneNumber` 按钮授权，将 `phoneCode` 与新的 `wx.login` code 交给后端；需账号具备微信手机号能力，且真实登录能力已配置。后端会按微信身份/手机号匹配账号并拒绝冲突。演示账号不模拟绑定成功。
- 手机登录调用实际的发送验证码与登录接口，生产后端需配置短信供应商。演示服务只展示演示验证码，并明确提示未发送真实短信。
- 购买创建服务端订单，正式环境调用 `wx.requestPayment`。客户端成功回调后仍查询服务端订单确认支付结果，未确认时提示刷新；订单列表支持继续支付。生产后端需配置微信支付与回调，且付款账号需拥有对应微信身份。
- 学习页使用后端校验权限后生成的视频地址，约每 10 秒、暂停、离开时上报进度。视频自然结束标记课时完成。后台上传正式视频前，种子课程可能使用明确标注的演示视频。
- 讲义通过带 `Authorization: Bearer` 的 `wx.downloadFile` 下载，Office/PDF 用 `wx.openDocument` 预览，并打开菜单用于保存。TXT/Markdown 打开本地文本预览，支持选择与复制全文。其他格式保存到小程序本地文件空间，不能保证设备可预览。每次下载仍由后端核验购买权限。

## 验证范围

代码可做 JSON、JavaScript 语法与页面引用静态检查。当前未声称通过微信开发者工具编译、真机预览、真实微信认证、真实短信或真实付款验收；这些检查需要真实小程序与商户配置后完成。
