# 回声测距实验室

回声测距实验室是物理工作台中的独立工作区。点击顶部“回声测距”，或直接访问 `/#echo`。登录弹窗提供“直接打开回声测距实验室”入口，无需填写 SK。

## 使用流程

1. 粘贴一道完整题目，保留数字、单位、运动方向和各小问。
2. 生成模型，核对命中的关键词、模型类型和提取出的物理量。
3. 补全缺失参数；确认题目中的对象是在靠近、远离还是保持静止。
4. 播放仿真，观察发声、反射和接收三个时刻，比较声音传播路程、物体位移及发声和接收时的距离。
5. 调整参数进行对比，保存或导出模型，以便后续教学和训练样本整理。

默认选择“DeepSeek 优先 · 失败回退本地”：点击生成时，使用当前连接设置中的服务地址与 SK，专门调用 `deepseek-v4-pro-zy` 整理题意。无需修改其他实验室的默认模型。无连接、超时、格式错误或条件核验失败时，自动切换本地规则并显示原因；打开页面和载入示例本身不会调用模型。

选择“仅本地规则 · 无需联网”时，关键词识别、单位换算、模型匹配均在浏览器完成，不发送题目。两种模式的物理计算和动画均由本地求解器执行。DeepSeek 的每个数值都必须引用题干原文，经过单位、模型方向、已知条件与物理关系核验；未给声速不会从参考答案补填。

## 题目输入

推荐一次输入一道题。含多个小问的题目可以保留全部题干，但不同物理情境需要分别核对。速度建议写作 `20 m/s` 或 `72 km/h`，时间写作 `2 s`，长度写作 `360 m`；也支持常见中文单位。

从题库网页复制的内容可能丢失公式和数值。例如“汽车以的速度行驶，经过后听到回声”仅保留了情境，无法求出数值答案。此时实验室应显示缺失参数，等待手动补充；教学演示参数不属于原题已知条件。

图示方位、仪表盘读数、时刻表和超声波时间图像需要转录为文字数值。仅有“如图所示”不足以恢复图中信息。

## 物理约定

- 默认按一维直线传播分析，声速相对于空气或水保持恒定。
- 反射时间忽略不计，运动对象按相应模板规定的运动状态计算。
- 声音的往返时间对应发射到接收的整个过程，发声位置与接收位置可不同。
- 距固定障碍物匀速靠近时，若声速为 `c`、物体速度为 `v`、回声时间为 `t`，则发声距离为 `(c + v)t / 2`，接收距离为 `(c - v)t / 2`。
- 匀速远离时，发声距离为 `(c - v)t / 2`，接收距离为 `(c + v)t / 2`；静止时两者均为 `ct / 2`。
- 声源、接收者或反射目标分别运动时，必须按具体模型求解相遇条件，不能直接套用静止测距公式。

仿真为教学示意。画面中的车身、山体和声波尺寸不代表真实比例；数据计算以参数和模型方程为准。

## 后续训练资料

每份资料尽量包含完整题目、正确模型类别、参数及单位、正确答案，以及题目依赖的图示说明。应同时收集同一模型的不同措辞，以及容易混淆的反例，例如“驶向 / 驶离”、“地面 / 海底”、“反射回声 / 直接听到鸣笛声”。

新增样本可改善相似题的本地匹配；新增物理模型还需要对应的参数约定、求解器与仿真表现。超出模型支持范围的复杂情境应明确提示待扩展，不能强行归入基础模型。

## 第一版范围

7 个可计算模型：静止、匀速靠近、匀速远离、无人机下降、无人机上升、声呐测深、同向移动反射目标。可输入回声时间求距离，或输入初始距离反求时间；列车长度、隧道长度、速度、完全通过时间可组成附加计算。减速与多次回声、不同接收者、侧向车位扫描已建立专用分类，暂未实现求解器。

已补充：已知初始距离、声速和回声时间反求运动速度；给定初始距离和运动路程反求速度与时间；回声后到达障碍物所需时间；桥头位移、列车长度及车厢节数计算。

“载入真实例题”包含本次提供的 17 道题，输入只保留题干。第 6、12 题有多个情境：本地模式可点击对应小问，DeepSeek 模式通过“物理情境”切换模型。批量粘贴带“【主观题】”等标记的材料时，先选一题；“【解析】”以后的答案和资料会从实际解析输入中排除。

本批题的调用与对照结果见 [DeepSeek 对照测试](echo-deepseek-evaluation.md)。当前只验证了这批回归题，不代表对所有新题的识别率。

内置 11 条完整教学示例，数值为自编演示数据，不是参考试卷的原始数据。正式题目会提取自身数字；不会从样本库拷贝数值来填充未知条件。

参数识别支持常用中英文单位、全角数字和中文数字；例如 `72 km/h` 转为 `20 m/s`、`200 ms` 转为 `0.2 s`。明确的物理情境规则优先，本地样本以中文字符二元组相似度及关键词命中辅助排序。规则可能无法涵盖所有措辞，参数附近会展示原文来源，供核对及修正。

## 样本文件

在“模型与样本”中下载样本模板，或导入 UTF-8 JSON 数组。最多 1000 条，文件不超过 2 MB。同编号样本会替换旧内容。

```json
[
  {
    "id": "rizhao-001",
    "title": "汽车驶向山崖",
    "text": "在这里填写包含完整数字和单位的题目",
    "modelId": "approaching",
    "keywords": ["驶向", "开过来", "前方山崖"]
  }
]
```

模型编号依次为 `stationary`、`approaching`、`receding`、`descending`、`ascending`、`depth`、`moving-target`、`decelerating`、`two-receivers`、`parking`。

点击“将这道题收录为训练样本”可直接标注，不必手写文件。这里的训练是积累标注样本并参与本地检索，不是大模型训练；样本不会自动生成新的物理算法。

工程导出包含题目、确定模型编号、提取参数、手动参数、匹配依据、计算结果与事件时间、样本库，可重新导入。浏览器草稿使用独立键 `echo-lab.draft.v1`，与电学和光学分开保存；样本不会跨设备自动同步。
