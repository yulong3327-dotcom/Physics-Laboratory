# 实验与导出

## 开始实验

1. 放置电源、开关及用电器，将接线柱连成回路。
2. 选中元件，在“实验参数”中设置电源电压、内阻、阻值或额定参数。
3. 点击工具栏“实验”。画布显示状态与总供电电流，属性面板显示选中元件的电流、端电压和功率。
4. 开合开关或移动变阻器滑片，结果会按当前接线重新计算。参数修改可撤销，停止实验后仍保留接线和参数。

“未接入电源”表示没有有效正电压电源；“开路”表示没有有效供电电流；“通电”表示存在供电通路；“短路”表示电源两端存在低阻通路。“无法求解”会保留错误提示，不生成无意义的读数。

这些状态描述当前电学模型。总供电电流是各电源正向输出电流之和，多电源电路中不能将它当作每条支路的电流。各不相连的电路分别选择零电位，不能用不同独立回路的参考电位直接相减。

## 电学模型

求解器使用线性直流稳态节点方程和 `ml-matrix` 数值求解库。导线连接的端点视为同一电节点；导线无独立电阻、长度损耗或寄生参数。电源是理想电压源串联有限内阻，电流表和电压表也具有有限内阻。因此测量支路可能轻微改变被测电路。

默认电池组、直流电源为 3 V，单节电池座为 1.5 V，默认电源内阻为 0.1 Ω。这些值是可编辑的实验初值，并非通过素材图片确认的铭牌值。闭合开关及数值上为零的电阻使用最小 `0.0001 Ω`，避免理想短路产生无限电流或不可解方程。电源两端存在总阻值不超过 `0.1 Ω` 的通路时提示短路。

求解规模上限为 180 个元件、1200 条导线。电阻在数值求解时限制在 `0.0001 Ω` 至 `1e9 Ω`。极端参数仍可能造成方程失稳，此时显示求解失败。导线交叉本身不增加电连接，只有工程数据中的端点连接确定电节点。

模型不包含交流频率、寄生电容、电感、开关火花、电池化学反应、热过程和动态储能。动画各帧都是参数变化后重新求得的稳态结果，时间长度不代表电路的真实响应时间常数。

## 灯泡与负载

灯泡默认额定电压 3 V、额定功率 0.3 W，以 `R = U额定² / P额定` 得到恒定电阻。实际功率按电路计算，显示亮度按 `P实际 / P额定` 限制在 0 至 1。超过额定功率的 120% 会提示过载；模型不会自动烧断灯丝，也不模拟冷态灯丝电阻变化。

实物灯泡使用固定的未点亮底图，仅改变局部发光层的透明度；开关使用固定底座和绕铰点旋转的刀片层。状态变化保持底图尺寸、宽高比与接线柱位置，不会通过压缩整张图片表现亮灭或开合。电路符号同步显示通电亮度和开关状态。

定值电阻可直接设置阻值。电机默认等效电阻 15 Ω；电铃和蜂鸣器默认 100 Ω，可调整。电机反电动势、转速、机械负载和电铃振动未建模。两脚蜂鸣器的图片无法确认有源或无源、极性；当前将其作为直流等效负载，显示通电状态，不产生声音，也不模拟无源蜂鸣器所需的交流驱动。

## 仪表

| 仪表 | 公共负端 | 低量程正端 | 高量程正端 | 默认低量程内阻 |
| --- | --- | --- | --- | --- |
| 电流表 A | `left` | `right`，0.6 A | `high`，3 A | 0.02 Ω |
| 电压表 V | `right` | `left`，3 V | `high`，15 V | 1 MΩ |
| 灵敏电流计 G | `left` | `right`，默认满偏 3 mA | 无 | 100 Ω |

电流表串联在待测支路，电压表并联在待测元件两端。A/V 量程由实际接入的正量程端子确定；公共负端必须接入，一次选择一个正量程端子。高量程 A 的等效内阻为低量程的 0.2 倍，V 为低量程的 5 倍。G 的满偏电流可在属性面板设置。

A/V 在电路图中默认显示左右两端。低量程或高量程接线都使用两端符号；高量程 `high` 投影到原低量程正端的位置，工程中的端口 ID 和连接保持不变。实物图始终保留三个接线柱。若三个柱都已接线，电路图也显示三端，以保留可诊断的真实接法；误接两个正端时保留两个实际端口，不会悄悄改为公共端接线。

尚未连接正端时，可在电路图属性中选择“接线量程”，再连接该量程端子。正端已有导线时量程选择锁定；需要换量程，应先删除对应接线，或切到实物图重新连接目标接线柱。

“自动测量”根据计算结果驱动 A/V 指针；“手动设针”使用输入的手动读数设置指针，适合读数练习。手动值不会注入电源、改变回路电流或覆盖属性面板中的实际测量值。反接、超量程、端子悬空、同时接入两个正量程端子时会显示相应提示。指针视觉位移有边界，超量程状态仍通过警告呈现。

A/V 使用去除固定旧指针的实物底图，保留原有刻度及外壳；导线接在柱帽下方夹线螺母。G 当前更新数值读数，原图蓝针未拆分为活动图层，不能把原图蓝针当作实时指示。

## 滑动与旋钮调阻

滑动变阻器的 `a/b` 是电阻丝两端，`c/d` 是同一导电滑杆的两端。设置最大阻值 `Rmax`，滑片位置 `s` 为 0 至 1，则 `A 到滑片 = Rmax × s`，`滑片到 B = Rmax × (1 - s)`。

- 接 A 与 C/D 时，向 B 移动滑片会增大接入阻值。
- 接 B 与 C/D 时，向 B 移动滑片会减小接入阻值。
- 只接 A、B 时接入全部阻值，移动滑片不改变总阻值。
- 只接 C、D 不接入电阻丝，会提示低阻连接。

选中实物变阻器后，可用画布滑块或参数面板滑块调节位置，图片中的滑片同步移动。滑片移动时固定接线柱保持原位置。

三端旋钮电位器以 `a/b` 为电阻两端、`w` 为滑动端，采用相同的两段电阻模型，既可作为两端可调电阻，也可作为三端分压器。素材图中的 A/W/B 分配是实验示意，实物引脚顺序应依据器件资料或测量确认。

## 导线电流动画

实验运行时，发亮的黄色小点沿每条有电流的导线移动。方向为常规电流方向：单电源外部回路通常从正极经过负载流向负极。每条导线使用自身的计算电流，不把总供电电流复制到所有支路；工程中调换导线的起终点仅改变电流的符号表示，不改变物理流向。

导线电流按各接线柱的元件电流注入量和基尔霍夫电流定律重建，包含滑动变阻器内部 C/D 导电滑杆。理想导线构成冗余闭环时，单条导线的电流分配没有唯一物理解；应用采用各导线等权、满足节点电流守恒的最小范数解用于显示。这不表示已计算导线长度、电阻或真实并行线缆的分流比例。

黄点速度随电流大小变化，但只是便于观察的示意，不代表电子漂移速度、信号传播速度或真实电荷数量。电流绝对值低于 `0.00001 A`（10 µA）时不显示粒子，因此高内阻电压表的微小测量电流可能没有可见黄点；数值读数仍按模型计算。停止实验或电流为零时不显示电流粒子。电路图沿直角导线运动，实物图沿自然弯曲线缆运动。

## 录制实验过程

点击“录制实验”开始记录；应用同时启用实验。随后进行开关开合、阻值和滑片调节、停止或重新开始实验等操作，结束时点击“结束录制”。录制按原始时间保存电路与参数快照、实验启停状态；图形位置和接线改变也会记录，选择、缩放和平移不计入实验事件。录制使用开始时的视图，后续视图切换不改变该次录制的输出模式。

单次录制最长 60 秒，达到 1500 条状态记录（含初始状态）也会自动结束；极短操作保留至少 0.25 秒。载入或新建不同电路会结束当前录制，避免混入不同工程。结束录制不自动停止实验。开始下一次录制会替换当前暂存录制。

录制仅在当前页面内暂存，刷新或关闭页面后丢失，也不包含在普通工程 JSON 或本地草稿中。录制快照不包含 AI 识别参考原图，避免每次参数变化重复保存大图片；这不会删除原工程中的参考图。可通过 MP4/WebM 保存播放结果，或通过 Manim ZIP 保存带原始时间戳和工程快照的 `timeline.json`。当前没有录制文件导入与时间轴编辑功能。

## 导出工程与图片

在工具栏打开“导出电路”，选择格式。SVG/PNG 可选择是否包含实验读数。视频和 Manim 可以导出已经录制的实验过程，或根据预设重新计算各帧的电学状态；导出包含开关状态、灯泡亮度、仪表指针和电流黄点。

JSON 包含 `schemaVersion: 2`、当前 `viewMode`、元件与端口 ID、导线连接、素材 ID、`position`（电路图位置）、可选 `realPosition`、`orientation`、`realOrientation` 以及实验 `parameters`，可重新导入。导线的 `routes.schematic.points` 与 `routes.real.points` 分别记录两种视图的手动路径。旧文件未提供 `realPosition` 时以电路图位置作为初始参考，任一视图编辑后独立保存；两种视图始终共享电气连接和参数。工程引用项目内素材 ID，不打包原始图片；旧版本工程仍可通过兼容导入补齐标准端口。当前导入文件大小上限为 2 MB。浏览器运行状态、撤销历史不属于工程快照。

SVG 内嵌所有使用的实物 PNG，离开应用服务器后仍可显示。SVG 中的电路符号和导线保留矢量路径，实物图片仍是位图。PNG 输出为 1280 x 720 的白底图片。输出范围根据实际元件和导线路径计算，不依赖画布当前缩放和平移。中文文本使用查看设备可用的字体，未将字体打包。

图片与动画使用对应视图的位置和手动导线路径，电流黄点沿调整后的线缆运动。录制保存每次布局和路径变更，以录制开始时的视图重放。切换查看另一视图不会移动已摆好的元件；工具栏“自动整理”只更新当前视图的位置和走线。

## Manim 工程包

导出 ZIP 后得到以下文件：

| 文件 | 用途 |
| --- | --- |
| `scene.py` | 可运行的 Manim Community 场景 `CircuitExperiment`。 |
| `project.json` | 可重新导入编辑器的完整电路工程；录制导出时为录制初始工程。 |
| `circuit.svg` | 工程的独立图像快照。 |
| `timeline.json` | 原始录制时间、工程快照与实验启停事件，或选定的预设信息。 |
| `frames/*.png` | 以 24 fps 重放得到的每帧画面，帧数为时长乘 24 后取整。 |
| `README.md` | 运行前提与命令。 |

运行环境需已有 Python 3.10+、Manim Community 和 FFmpeg。进入解压目录后执行：

```sh
manim -qm --fps 24 scene.py CircuitExperiment
```

`scene.py` 使用 `ImageMobject` 以 24 fps 顺序播放已计算的 PNG 帧，保留录制时的参数变化和实验启停节奏。可编辑该 Python 场景添加文字、旁白配合或其他 Manim 内容；电路元件没有转换为各自独立、可编辑和插值的 Manim 对象。`timeline.json` 保留事件数据，但 `scene.py` 本身不求解电路或自动从修改后的时间轴重生成帧。需要改变电路计算参数时，应回到编辑器修改工程并重新录制或导出。

尚未在本机实际运行 Manim 渲染。导出包生成和浏览器视频编码可独立验证，不代表已验证外部 Manim 环境中的实际渲染。

## 视频与实验预设

MP4 使用 H.264，WebM 使用 VP9，通过浏览器编码器生成，分辨率 1280 x 720、24 fps，无音频。录制导出使用原始录制时长（0.25 至 60 秒），预设时长可设为 2 至 30 秒。此路径不调用本机 FFmpeg。浏览器必须实际支持对应编码器；不支持时显示明确错误，可改用另一视频格式或 Manim 工程包。

录制视频每帧使用该时间点最近一次保存的工程与启停状态，重新计算并绘制画面，按原时序呈现开关、调阻、灯泡、仪表和电流移动。它不录入鼠标、属性面板、画布平移缩放或浏览器界面。24 fps 会量化可见事件时间；短于一帧的状态可能不会单独出现。预设与录制使用同一套绘制和电学计算。

| 预设 | 变化 |
| --- | --- |
| 已录制的实验过程 | 按实际时间重放已结束的录制，包含参数变化与实验启停。 |
| 当前电路电流动画 | 保持当前接线和参数，通电导线上持续播放电流黄点。 |
| 开关由断开到闭合 | 所有普通开关在前 20% 时段断开，随后闭合；不改变单刀双掷开关。 |
| 滑片从 A 端到 B 端 | 所有滑动变阻器和旋钮电位器的位置从 0 同步变到 1。 |

没有对应元件时相应预设不可选，没有已结束的录制时不能选择录制过程。预设和录制导出不会修改画布上的当前工程；目前没有自由时间轴或逐元件事件编排编辑器。导出可以取消，取消后不下载未完成文件。
