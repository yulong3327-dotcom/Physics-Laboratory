# 光学仿真实验室

光学实验室与电学实验室平行，使用独立的场景、撤销历史和本地草稿。通过应用中的实验室入口切换，光学实验不会修改电学电路。画布保留浅色背景、网格与属性面板风格，器材采用深色轮廓、浅蓝玻璃填充的二维教材插图。

## 实验流程

1. 从组件库添加或拖入光源、物体、透镜及其他器材，也可以载入常用实验预设。
2. 在画布上移动组件，选择组件后在属性面板调整焦距、口径、物高、光线数量等参数。透镜焦距以厘米显示；“水平 / 垂直”按光轴方向设置，也可通过旋转角设置任意方向。
3. 运行光线，观察实际传播路径与成像分析；打开“虚像与反向延长线”可查看虚像及出射光的反向延长线。多片同轴透镜显示各级中间像、最终像、物距、像距及相对于原物体的累计放大率。光屏记录到达屏面的光线。
4. 使用网格、坐标和主光轴对齐器材；缩放、平移画布以查看整个实验。拖动完成后可以一步撤销。
5. 光学场景自动保存在当前浏览器的本地草稿。可导出 JSON 以备份或交换实验，并在其他设备导入。

## 当前组件

共 13 类基础组件，提供 13 个常用实验预设：凸透镜成像、凹透镜发散、放大镜与虚像、凹透镜成像、平面镜反射、平面镜成像、凹面镜成像、凸面镜成像、激光笔反射、玻璃板折射、三棱镜折射、显微镜原理和望远镜原理。

| 类别 | 组件 | 可调整的主要参数 |
| --- | --- | --- |
| 光源与物体 | 平行光源、点光源、激光笔、物体箭头 | 光束宽度、发散角、光线数量、波长、物高；激光笔固定为一条光线，可调方向与波长 |
| 透镜 | 凸透镜、凹透镜 | 焦距、口径、位置、方向 |
| 反射 | 平面镜、凹面镜、凸面镜 | 口径、位置、方向；球面镜可调近轴焦距 |
| 折射 | 玻璃板、三棱镜 | 尺寸、折射率、位置、方向 |
| 辅助 | 光屏、光阑 | 高度、开口、位置、方向 |

显微镜与望远镜作为实验预设，由光源或物体和两枚普通凸透镜组成。标为“物镜”“目镜”的透镜分别支持移动、旋转、调整焦距与口径、复制和删除，也可继续添加透镜搭建更多级的光学系统。

显微镜预设中，物镜焦距为 4 cm，物距为 5.5 cm，两镜间距为 20 cm，目镜焦距为 6 cm。物镜先形成倒立中间实像，目镜再形成最终虚像，累计横向放大率为 −24。望远镜预设使用焦距分别为 24 cm 和 8 cm 的物镜、目镜，镜间距为 32 cm；平行光经过物镜形成中间实像，再经目镜平行出射，最终像在无穷远。

## 模型约定

- 世界坐标和所有长度使用厘米；角度以度为单位，在屏幕坐标中正角为顺时针。
- 激光笔以笔尖坐标作为发射点，沿自身正 x 方向发射一条理想几何光线，旋转器材即可调整入射方向。默认波长为 650 nm；笔身从发射点向后延伸，长度 12 cm。它可以经过透镜、平面镜、玻璃板、三棱镜及光阑，由光屏接收。导入时将合法的光线数量与发散角统一为 1 和 0。
- 凸透镜、凹透镜采用理想薄透镜和近轴几何光学模型。凸透镜焦距为正，凹透镜焦距为负；成像关系为 `1/f = 1/u + 1/v`，横向放大率为 `-v/u`。大角度入射、厚透镜和像差不在此模型范围内。
- 镜面无斜线的一侧为反射面，斜线侧为不透明背面，照到背面的光线被阻挡；可用“翻转反射面”旋转 180°。平面镜严格遵循反射定律，单面镜的像关于镜面对称，支持离轴物体和旋转镜面。
- 凹面镜、凸面镜使用真实圆弧截面与实际球面法线反射，圆弧顶点为器材坐标原点；近轴焦距分别取正、负，曲率半径 `R = 2|f|`。口径不得超过球面直径 `4|f|`，导入时拒绝不可能的几何尺寸。光线碰撞面与可见圆弧完全一致，能够显示球差和离轴像差。
- 单个球面镜的成像读数与箭头明确标为“近轴估计”，采用 `1/f = 1/u + 1/v` 与 `m = -v/u`；镜前实像的像距为正，镜后虚像为负。球面镜物体的朝向应与镜轴一致，物体可离轴。大口径、离轴或大角度下实际光线不一定汇聚于估计像，虚线始终沿实际反射光反向延长，不强制连接估计像。多镜面或镜面与透镜、玻璃混合系统只追迹光路，不给出单镜公式读数。
- 多透镜解析成像适用于沿光源发射方向排列、光轴重合的理想薄透镜序列，支持物体、点光源和平行光源。每一级的像作为后续透镜的物，支持实物、虚物及无穷远共轭；有限物体的放大率是相对于原物体的累计横向放大率。平行光源不提供有限物体横向放大率，望远镜的角放大率也不在当前读数范围内。
- 物体经透镜形成的有限位置像以箭头标示；如果光束尚未到达某级理论实像面就遇到下一片透镜，读数会标明“被后续透镜截取”，不在画布绘制该中间像。像在无穷远时仅显示读数，不绘制有限位置的像；点光源与平行光源的轴上像也不绘制有高度的成像箭头。
- 非同轴透镜仍可逐段追迹，但不提供上述解析成像读数；包含启用的镜面或玻璃介质、或存在重合透镜面时，也不提供透镜序列的解析读数。光屏与完全关闭的光阑会截断后续成像分析。部分遮挡和采样光线数量不用于计算亮度或像的可见度，应结合实际光路观察。
- 玻璃板与三棱镜在表面按斯涅尔定律折射，并在超过临界角时发生全反射。平面镜使用反射定律。光屏和不透明光阑遮挡光线。
- 透镜仅改变穿过有效口径的光线方向，超出口径的光线继续传播；需要遮挡时可添加光阑。同一位置的光阑与透镜会共同作用，通光开口之外的光线被阻挡。
- 光线为几何路径，虚光线是反向延长的观察辅助线。光线数量影响显示采样密度，不代表光功率或量子数量。
- 波长用于光线显示颜色；材料使用可调的单一折射率。模型不模拟材料色散、干涉、衍射、偏振或波动光学。
- 每个场景最多 100 个组件，每个光源最多 41 条采样光线；每次最多追迹 512 条光线，每条光线最多经过 32 次交互，达到上限时显示提示，避免反射腔等结构无限追迹。

## 二维教材组件样式

元件库、属性面板、放置预览及画布使用 `src/optics/OpticalSymbol.tsx` 中的代码原生 SVG 符号。透镜和介质以简洁轮廓表示光学截面，配合浅蓝填充；镜面、光屏和光阑用教材线稿表示，激光笔保留易识别的笔身与红色出光口。组件随参数调整，无需预生成图片素材。

物体箭头、实像箭头与光线方向箭头采用参考图中的纯蓝色实心样式，由矩形箭杆和三角箭头组成；虚像采用相同几何轮廓，以蓝色虚线描边和浅填充区分。物体与像的箭头高度、方向分别对应物高和像高；光线方向箭头指示实际传播方向。光线路径仍按设置的波长着色，虚光线以反向延长的虚线表示。此样式调整仅作用于组件和箭头，画布保持浅色背景。

所有组件沿本地正 x 轴定义光轴或发射方向，透镜、平面镜、光屏与光阑的交互平面位于本地 `x=0`，球面镜顶点为原点，反射面朝本地负 x 方向。镜面背部斜线沿圆弧法线偏向背面绘制。激光笔笔尖对应发射原点。组件轮廓与光学有效尺寸相配合，光阑开口随参数变化；组件边界用于点选和拖动，“适应画布”同时考虑组件范围与已计算的有限位置像。

## 数据与扩展

光学数据具有 `schemaVersion: 1` 与 `kind: "optics-lab"`，持久化键为 `optics-lab.draft.v1`。无效导入不会替换当前场景；恢复时遇到损坏的草稿也不会自动覆盖原内容。本地存储不可用时仍可编辑、撤销、导出 JSON。

旧版本 JSON 或本地草稿中的显微镜、望远镜组件会自动转换为两枚普通凸透镜及两个光阑，保留原物镜、目镜的位置、光轴方向、焦距、通光开口和启用状态。转换后的元件可分别编辑；展开后的组件数量与坐标仍须满足场景限制，校验失败不会覆盖当前场景或原草稿。

组件的类型与参数位于 `src/optics/types.ts`，组件定义与预设位于 `src/optics/library.ts`，传播规则位于 `src/optics/simulation.ts`，球面镜公共几何位于 `src/optics/mirrorGeometry.ts`。新增器材时需同时加入组件定义、渲染、交互属性、解析验证及对应的传播规则。可在此基础上继续添加分光镜、光纤与测量工具。
