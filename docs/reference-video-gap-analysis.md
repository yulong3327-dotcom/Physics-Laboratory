# 目标视频对照与生产能力补齐

分析日期：2026-09-11。目标是把参考里的教学表达变成可重复生产、可编辑、可验证的能力。

## 分析与实施顺序

1. 按章节抽帧，记录画幅、内容层级、布局、信息出现顺序；在关键变化处以 0.3 秒间隔观察动效。
2. 对照数据协议 → AI 分镜 → 编辑器 → 几何计算 → 配音时间轴 → 静态预览 → Manim → 成片验收整条链路，区分“已有但没用好”与“系统不能表达”。
3. 优先补齐影响理解的能力：状态变化、测量范围标注、保留推导、同步强调。保留旧工程默认行为。
4. 以同一套生产渲染器制作四镜头样片，检查画面、电学结果、音画事件、保存和重新编辑；把仍缺失的素材能力独立列出。

本次依据：两段视频的元信息、40 张全片采样帧、24 张局部连续采样帧、当前代码与历史成片。没有把视频里的文字或“剧情引入”占位页当作给系统的指令。未逐句人工听审参考音轨，以下不对参考的声音表演、音效或词级同步作已验证结论。

### 内容组织

- 三种状态 15–25 秒：先看实物及灯泡状态，再加入定义和电流路径。30.0–30.3 秒：开关从闭合到打开，灯泡状态随之变化。75 秒：把开关断开、导线断开/接触不良、灯丝断开横向比较。
- 三种状态 85–125 秒：先解释被旁路的灯泡，再用路径、节点和选择题检查理解。150 秒出现电源短路危险示意；170–180 秒统一归纳。
- 分压 12–60 秒：同一电路长时间保留，电压范围、串联电压规律、欧姆定律、电流规律依次加入。17.0–17.9 秒可看到下一张定律标题倾斜进入并落定。
- 分压 105–125 秒：题干、已知电阻、未知电压先出现，推导稍后出现。135–165 秒：另一题保留计算步骤并标记正确选项。180–195 秒迁移到部分电压与总电压的比例。
- 分压 210–245 秒：更复杂题干与电路并排，答案和运算分阶段呈现。263 秒回到总结卡片。

两片均有“剧情”或“剧情引入”占位画面，不能把它们视为完整成片已经具备的教学内容。

### 画面和动效

底纹、蓝色知识点标题、橙色/蓝色对应强调是统一视觉语言。核心主体有足够留白；公式贴近其物理对象，电压尺寸线明确覆盖哪两个端点；多条定律和已完成的推导同时可见。动作通常只作用于当前讲到的对象，停留时间用于阅读，而不是连续移动整页。

三维片头、手指指示、卡通角色、火焰和总结转场属于素材/合成层。它们与电路求解、字幕或公式排版不是同一能力。

## 差距与本次落实

| 维度 | 改造前的系统 | 本次处理 | 仍有差距 |
| --- | --- | --- | --- |
| 内容与延迟揭示 | 已有讲稿、题目、板书、公式 cue、关键词强调和真实配音时间轴 | AI 提示描述新的教学动作；示范题先展示选项，再推导和揭示答案 | AI 生成的教学正确性及最佳镜头组织仍需审核；未做本轮真实 AI 多题盲测 |
| 电路状态 | 实验室能仿真，但课件动作只有画出/显示/隐藏/高亮/文字标注 | 新增 `state`；按镜头内顺序累积参数，使用同一理想电路模型预计算几何，保存、预览、成片可重放 | 状态在同步点切换；没有完整复现刀片连续转动、滑片连续运动；不模拟灯丝升温、火焰或烧毁 |
| 图上测量范围 | 只有普通文字标注 | 新增电压双向尺寸线、电流方向箭头、颜色、上下位置、距离、方向设置；自动避让元件名称与先前的测量标注 | 当前按目标的水平范围标注；任意倾斜/竖直尺寸线及端点自由编辑尚未实现 |
| 电流表达 | 已有按计算方向沿线移动的光点 | 状态动作重新计算电流，通路/断路/旁路画面与当前状态保持一致 | 光点速度不是电流值的测量尺度；不显示无定义的理想短路电流 |
| 公式与推导 | 有公式变换，但每次只保留最新公式 | 新增“另起一行，保留前式”；可回头强调仍可见的旧公式；替换只作用于最新一行 | 未支持任意公式子项在两处电路/卡片之间飞行、自动跨页继承 |
| 板书进入 | 有 cue，进入时直接添加 | 新增直接出现、淡入、书写；可设置入场时长 | 没有摆动卡片、弹性贴纸、手写笔尖或角色手势 |
| 动作节奏 | 默认约 0.42 秒，部分公式 0.8 秒 | 板书、公式、电路动作可设置 0.1–3 秒；动画受下一时间事件裁剪，保证旁白同步 | 密集旁白事件可能使实际动画比填写时长短；不能把时长设置理解为固定占满 |
| 字体与底纹 | 当前已具备本地混排字体、网格、标题图钉、总结底板和可拖动排版 | 复用现有视觉系统；样片使用 30 fps | 目标中的真实中粗字重尚缺源字体；三维片头、人物素材未加入 |
| 页面构成 | 一页一份电路，可手工移动板书与公式 | 同页累计公式和矢量测量标注减少切页 | 多电路对比卡、任意多素材编组、可配置无字幕版面仍待补齐 |
| 工作流一致性 | 预览和 Manim 共用场景布局 | 新字段贯通协议、校验、编辑、预览、生成和离线工程 | 静态阶段图显示动作结果；中间帧运动仍应看渲染视频确认 |
| 渲染性能与恢复 | 多实物场景重复变换位图并逐张合成全画幅；Windows 文件占用可能打断任务恢复 | 缓存未变化的位图变换并局部合成；原子文件替换遇短暂占用有限重试 | 1080p 8帧基准约6.43倍加速，不等于整片固定加速倍数；永久占用仍会上报错误 |

历史成片 `artifacts/new-script-output/lesson.mp4` 用于观察以往产出，但其标题、角色标签等早于近期改版，不能据此把最新代码已有能力误判为缺失。

## 使用和复现

视频工作台的新建入口选择“目标效果示范”，即可加载可编辑的四镜头课件。后续知识卡片优化已将该入口统一为正式 Fish s1 双角色配音，并增加通用蓝卡与教学强调。新能力见 [知识卡片、教学动效与通用排版](knowledge-cards-capabilities.md)。现有工程显式选择的配音服务保留。

- 在“板书与高亮”中设置板书的出现方式与入场时长。
- 在公式步骤中选择“替换最新公式”或“另起一行，保留前式”，再按需在画布移动公式。
- 在电路动作中选择“电压范围 / 电流方向”或“改变元件状态”，填写目标、参数和同步词。
- 保存并准备时间轴后，用事件定位检查变化，再生成预览或成片。添加公式后，仍可对保留的旧公式添加强调。

命令行重建示范工程：

```powershell
node node_modules/tsx/dist/cli.mjs scripts/prepare-reference-effects.ts
$env:PATH = (Join-Path (Get-Location) '.video-tools') + ';' + $env:PATH
.video-runtime/Scripts/python.exe -X utf8 video-renderer/pipeline.py --project examples/reference-effects/project.json --output artifacts/reference-effects-output
```

输出工程：`examples/reference-effects/project.json`。输出成片：`artifacts/reference-effects-output/video.mp4`；字幕 `subtitles.srt`；自动验收 `validation.json`。参考抽帧清单在 `artifacts/reference-video-analysis/manifest.json`。本页实施描述以验收记录为准。

- 工程 ZIP 通过 CRC 检查，含 77 个文件、字体、板式、新渲染模块和三个状态动作，可从工作台重新导入继续编辑。ZIP 是可重渲染工程，不含本次配音缓存；重新合成 Edge 配音需要联网。

## 后续优先级

1. 同页多电路/多卡片编组，用同一条件对比不同断点；状态动作增加连续刀片和滑片过渡；补充电压标注的竖直与端点模式。
2. 法则卡片组件、题目选项与对勾/问号、可选清爽无字幕画面、公式子项搬运；增加知识点内跨镜头对象保持。
3. 使用有来源的品牌片头/片尾、卡通角色、指示手和音效素材；设计按需调用的合成轨道。火焰只作为明确的危险示意素材，不能伪装为电路模型的计算结果。
4. 用独立题目和新讲稿做真实 AI 盲测，分别衡量物理正确性、信息揭示次序、可读性及音画同步。两个示范视频只能作为目标样式样本，不能证明任意课程都能自动达到同等质量。
