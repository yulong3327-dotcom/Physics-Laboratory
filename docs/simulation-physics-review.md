# 电学与光学仿真排查记录

本轮针对可复现的物理逻辑错误修复，并同步到独立部署版及管理端物理实验室。本文记录修复及验证方法；线上版本以对应仓库的部署记录为准。

| 问题 | 根因与修复 |
| --- | --- |
| 物体离开主光轴后实像、虚像消失 | 原成像筛选误把“物体底端在主光轴上”当成条件。现在只要求透镜序列同轴，像的底端和顶端均按放大率映射横向偏移，支持整体旋转及多级成像。 |
| 物体顶端在轴上时光线重合 | 三条主光线可能退化为同一条，现补选不同的口径光线。 |
| 三棱镜擦边光路错误 | 沿光线方向采样两侧介质时，擦边光没有越过边界容差。现沿界面法线采样，并明确提示真实全反射的折射率和临界角。 |
| 镜面符号与反射逻辑不一致 | 三种镜面使用教材细线及镜背斜线；凹、凸镜的可见圆弧与实际碰撞面共用几何，按球面法线反射，背面吸收。加入反射面翻转及焦距、口径约束。 |
| 灯泡超过额定功率仍呈普通发光状态 | 删除额外的 20% 过载宽限；超过额定功率即标记过载，示意图、实物图、属性、导出和视频显示异常及实际/额定功率。 |
| 串联电池总电流被重复累加 | 实验及理想求解器改用电源组端口电流；并联电池扣除内部环流，多端供电与独立回路不强行相加。 |
| 并联、桥式或串联电源组的短路漏报 | 使用测试电压求无源网络的等效电阻，检查电源组外部节点；电源自身闭合短接环流单独告警，避免给出误导性的总电流 0。 |
| 高阻通路被判开路、真实微小电流被截零 | 开闭路由拓扑判定；电流和导线结果不再按固定绝对阈值截零，动画阈值仍限于显示层。0.001 V / 1 GΩ 回路保留约 1 pA 电流。 |
| 理想模型的极小有限电阻误判为短路冲突 | 对岛内电压、电流未知量按物理尺度归一化，进行残差修正；保留微小有限电阻和非零电源的区别。 |
| 数值残差导致断路仍有极小电流 | 利用 KCL 将导电图中不存在替代路径的支路电流定为精确零，保留闭合回路中的真实微小电流。 |
| 三端变阻器读数含义错误 | 提供每段的电压、电流及功率；三端接线时不伪造一个二端等效电阻。 |

## 验证

- 独立部署仓库提供 `npm test`，156 项物理、状态与导出回归通过；GitHub Pages 构建流程会先运行这些测试。
- 独立版 `npm run test:e2e` 使用独立端口 5174，可直接测试免登录实验室。`E2E_BASE_URL` 可指定已启动服务；所有导航相对于站点根路径，适配 `/Physics-Laboratory/`。
- Pages 验收使用 `GITHUB_PAGES=true npm run build`，同样设置 `GITHUB_PAGES=true` 启动 preview 后，将 `E2E_BASE_URL` 指向含尾部斜线的 `/Physics-Laboratory/` 地址。实验室无需登录，也无需调用 AI 接口。
- 独立版 Pages 产物的桌面及手机界面回归：28 项通过。
- 工作台完整单元测试：718 项通过。最后对电源节点筛选及显示文案做微调后，相关电学测试 38 项通过。
- 光学、灯泡过载浏览器回归：28 项通过，覆盖桌面及手机，包括实际移动离轴物体、调焦、镜背遮挡及工程保存恢复。
- 镜背斜线缩放显示修正后，镜面桌面及手机测试重新通过，并检查实际截图。
- 管理端后端规定测试：516 项通过。前端 lint 通过，构建包含已有图片优化提示；三个版本均生成对应静态产物。

## 模型边界

- 透镜采用理想薄透镜近轴模型；球面镜实际反射保留像差，成像箭头明确标为“近轴估计”。多镜面、镜面与透镜/玻璃混合系统提供光线追迹，不套用单镜成像公式。
- 玻璃使用单一折射率，未模拟色散、菲涅耳反射分光、衍射或干涉。超过临界角没有折射光属于真实全反射。
- 电学为线性直流稳态模型，实验版包含有限电源内阻；灯泡使用额定参数对应的电阻近似。过载会告警，但尚未模拟灯丝温度变化及随时间烧毁。
- 实验版沿用外部等效电阻 ≤ 0.1 Ω 的教学短路判定，这不是通用于所有真实电源的安全阈值。电机反电动势、机械运动及瞬态过程仍未建模。

关键实现：`src/optics/simulation.ts`、`src/optics/mirrorGeometry.ts`、`src/lib/circuitSimulation.ts`、`src/lib/idealCircuitSimulation.ts`、`src/lib/wireCurrents.ts`。
