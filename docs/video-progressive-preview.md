# 分镜逐张预览

生成中的分镜在完成画面准备后立即写入独立预览快照，页面按快照版本自动更新，无需等待全课完成。预览不改变已保存工程；完整结果仍由用户审核采用。

- 知识点：每批模型 JSON 校验成功后，逐张准备电路几何并发布，随后才请求下一批。模型尚未返回完整 JSON 时只展示等待状态，不虚构已完成镜头。
- 剧情：有实际图片才计入完成画面；只有描述的页面显示“待生成图片”。自动剧情生图管线仍属于独立的后续工作，本次没有将文字候选包装成图片。
- 页面：默认展开实时画面，每组 4 张，支持翻页、跟随最新与放大。预览沿用正式场景布局。任务列表每 2 秒刷新，发现新版本再读取快照。
- 恢复：已完成快照在刷新、失败、取消、重启后保留；责任批次回滚时同步撤回受影响画面；恢复已有断点时避免进度先清零。
- 旧任务：首次查看无预览快照的已暂停任务时，可从匹配输入的旧断点重建画面，不请求模型。并发恢复任务或新快照优先，旧快照不能覆盖新结果。
- 校验：预览允许后续镜头尚未生成的公式引用，正式结果与成片校验仍要求全部引用完整。

存储：`tasks/<id>/partial-result.json` 先原子写入，再更新任务元数据。`GET /api/video/tasks/:id/partial-result` 返回只读工程、完成镜头 ID、文稿覆盖数量和快照版本；不返回模型原文、提示词、日志或断点。

验证记录位于 `artifacts/progress-unit-tests.log`、`artifacts/progress-final-targeted-tests.log`、`artifacts/progress-final-build.log`、`artifacts/progress-final-e2e.log`。端到端测试把第二张生成阻塞，确认第一张真实显示，刷新保留，随后追加第二张并模拟任务中断。实际旧断点另验证恢复 10 张、覆盖 12/29 段，第一张经本机 Python 渲染器输出 1920×1080、8 个场景元素；未调用付费模型。
