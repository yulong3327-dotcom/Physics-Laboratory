# 视频制作工作台

从实验室右上角“视频制作”进入，或访问开发服务的 /#video。视频项目与电路工程独立保存；原有电路实验和导出入口继续可用。

跨项目生产入口为 `/#video/production`。人工确认讲稿与分镜后，可一次选择多个项目加入后台队列，统一查看续作、取消和成片下载。批次重试、版本隔离与验收方式见 [视频生产平台](video-production-platform.md)。

“目标效果示范”可直接建立四镜头练习工程。板书可选淡入或书写，公式可另起一行保留前式，电路动画可添加电压范围、电流方向或改变现有元件参数。状态会重新计算灯泡和电流；图上标注会避开元件名称。完整范例分析、限制和复现命令见 [目标视频对照](reference-video-gap-analysis.md)。

## 本机启动

本机已在项目内安装隔离运行时。新建项目、内置课程、目标效果示范以及缺少配音配置的导入工程默认使用 Fish.audio s1 的方大招／金天练正式角色音色。已明确选择 Edge 或 Azure 的工程保留原服务与模型；服务不可用时明确报错，不会自动回退免费配音。Edge 验证和 Azure 仍可在文稿页主动选择。先运行 npm run dev，再打开终端输出的本地地址。

其他 Windows 电脑需要 Python 3.11+，执行：

~~~powershell
npm install
npm run video:setup
npm run video:smoke
~~~

Python 不在 PATH 时，可执行 scripts/setup-video-runtime.ps1 -PythonExecutable "实际的python.exe路径"。公式需要 latex 和 dvisvgm；课件中文使用内置方正兰亭圆，西文使用 STIX Two Text。环境检查页显示各项可用性。video:smoke 实际渲染中文、MathTex 和测试音轨，不使用 Azure，也不是正式课件。

如选择 Azure，在开发环境 .env.local 配置以下变量，生产服务使用 .env 或环境变量；保存后重启服务：

~~~dotenv
AZURE_SPEECH_KEY=你的AzureSpeech密钥
AZURE_SPEECH_REGION=你的服务区域
~~~

密钥只由服务端传给 Azure SDK，不写入网页、视频工程或 ZIP。选择 Azure 时，方大招固定使用 zh-CN-YunyangNeural，金天练固定使用 zh-CN-YunxiNeural。Azure 合成需要联网并按账号计费。

可选 VIDEO_PYTHON、VIDEO_FFMPEG 指定已安装工具的路径，VIDEO_DATA_DIR 指定项目存储目录。默认使用 .video-runtime/Scripts/python.exe、.video-tools/ffmpeg.exe 和 .video-data。首次环境安装需要网络，实际 Manim 渲染在本机运行。

## 从文稿到视频

1. 创建内置课程，或导入自己的文稿／视频工程 JSON。先保存讲稿草稿，核对后明确确认讲稿；内置课程仍保留原有十二镜头。
2. 提交后台分镜规划任务。先确定全课章节、台词归属和共享电路，再按教学段落细化；成功批次保存到服务端。关闭页面后继续运行，服务重启后自动恢复。
3. 在分镜页核对板书、公式、电路、旁白与教学数据。可以锁定镜头或对象，提交自然语言局部修改建议，查看前后差异后采用或撤销。
4. 保存并确认分镜，准备全镜头配音与时间轴。系统先检查全课静态内容，再准备全部真实配音；用音频播放器和事件定位检查出现时机。
5. 提交单镜头预览、整片预览或成片。所有请求绑定当前版本，自动验收通过后才能标为完成，并提供 MP4、SRT、报告、关键帧和工程 ZIP。

修改上游内容会使下游确认过期，此前分镜和成片保留。迟到 AI 结果单独保存，与当前修改冲突时展示差异；不会直接覆盖新编辑。内容错误定位镜头与对象后停止，网络错误每次最多三次尝试，仍失败则暂停等待继续。正式双人音色保持不变。详细接口、期限、恢复规则和实际验收状态见 [稳定生产与恢复](video-stability.md)。

章节标题、“总结页”和显式【题目】、【画面】、【审核提示】作为分镜说明保存并传给 AI，不进入配音。题设缺失时保留符号；题设与原台词答案矛盾时列入审核备注，保留原台词供审核。

原稿编辑与逐镜头旁白编辑分开。修改原稿可以立即保存草稿；确认新讲稿后重新生成分镜，旧分镜可从版本历史查看。未保存的编辑同时暂存于浏览器。原文中的科学表达提示不会自动改写旁白。学生故意提出的 10:5:2 标记为猜想，并明确连接后续逐项倒数的纠正步骤。

画布和分镜字段采用相同的编辑联动：整块板书或整条公式的高亮随文字更新；局部关键词消失、指定出现次数不再存在或目标被删除时，对应高亮自动移除。同一输入框中临时清空后重新输入原文，会恢复本次输入前的高亮与同步点。修改旁白使同步词消失时，相关画面改在该句句首出现，高亮不会早于其目标；请在画面阶段中复核新的出现时机。切换同步旁白会清除旧句关键词与偏移。

删除板书或公式会清理关联高亮及布局记录；公式步骤和电路动作均可在侧栏直接删除。被学生猜想引用的纠正公式需先解除引用。切换镜头电路会清除旧电路动作；从实验室删除元件后，只移除该元件及已删除导线的动画目标、绑定物理量和相应公式引用。删除当前选中的动画阶段后，舞台自动返回有效预览。

## 底纹、表头与电路画面

默认使用用户提供的网格底纹，图片等比铺满 16:9 画面、水平居中且顶部对齐，保留右上角装饰。底纹作为 data URL 保存到工程，导出与离线制作无需访问原始图片路径。文稿页可恢复指定底纹、选择纯色或上传替换。

视频表头只显示知识点总标题：有知识点标题覆盖时用 `shot.sectionTitle`，否则用项目标题。不再把内部镜头标题和章节序号放进视频画面；内部镜头名称仍用于导航和修改。

项目栏的“全课电路画面”统一选择标准电路图或实物图；选择器按素材实际视图显示共同模式或混合状态，单素材也可在“电路与数据”覆盖。实物图复用实验室图片、动态图层和真实端口位置，首次转换会生成独立实物布局；切换不会改变电气拓扑。保存时将图片内嵌到工程包。电流流动开关控制沿导线移动的光点，方向来自教材理想模型的确定电流，零电流、不唯一电流和纯符号图不播放。光点表示方向，速度不用于比较电流大小。

## 时间同步与重做

Edge／Azure 优先使用每段音频的实际词时间事件；同步动作由旁白 ID、原文关键词和可选偏移定位。Edge 若无法将词事件完整对应原文，则按标点和同步点拆分为真实配音片段，用实测片段时长对齐。找不到关键词或无法取得对应音频会报错，不按猜测的语速生成正式片。

字幕沿用原文，字母与下标发音单独处理。工程可选 pronunciations 数组，例如 {"text":"P1","spoken":"P 一"}。更改配音文本、声音或发音配置会使相关音频缓存失效。公式与电路变化仅影响引用它们的镜头；整片重新合成时复用未变镜头。每镜头时长按视频帧对齐，整片音频统一编码，避免分段编码延迟累积。

任务和项目保存在 .video-data；服务重启后自动恢复未完成的后台步骤，渲染继续使用原提交快照与已验证缓存。预检和渲染共用串行媒体队列。本机同一数据目录只由一个服务实例管理，开发服务与生产服务应分别使用不同 VIDEO_DATA_DIR，或只启动一个视频服务。

## 电路图库与理想模型

CircuitGraph 保留原有拓扑与编辑格式。视频工程引用快照，另存教学物理量及呈现时机。

exportCircuitGeometry 导出独立元件 SVG、导线路径、端口和稳定 ID。几何坐标沿用编辑器的 x 向右、y 向下；元件 x/y 为全局中心，端口为全局坐标。Python CircuitMobject 提供 component(id)、wire(id)、port(componentId, terminalId) 和 resolve_target(id)，分组平移、缩放后端口锚点仍随图形移动。标准电路使用独立矢量元件；实物图使用内嵌图片及矢量叠加层，并在网页预览和 Manim 中沿同一条导线路径播放电流光点。

simulateIdealCircuit 提供独立教材理想模式。电源、电流表和闭合开关采用严格电压约束，电压表不分流；采用秩与零空间区分确定量、不唯一量和矛盾约束。旧 simulateCircuit 继续使用有限内阻实验模型。数值题验证使用理想模式；符号推导不使用虚构的参数运行数值仿真。

题设量、推导量、符号量分别标记；推导值可通过 revealStepId 指定出现步骤；显式 componentId 可把物理量绑定到指定元件，无下标的 U/I/P/R 分别按电源总电压、总电流、总功率和等效电阻复核，兼容 P1、P_1、P₁、P_{1} 等下标形式。只供内部验证的推导电压不指定出现步骤，不在视频中展示。

## 题目讲解、全课样式与板书

入口可选择“文稿”或“题目”。题目支持文字和PNG/JPEG/WebP图片，原题与AI解析、答案、配音讲稿分别保存。先生成解析讲稿，再由老师核对并明确确认当前讲稿，之后生成分镜。未生成分镜的题目草稿可保存和恢复，但不能误批准或渲染。题图继续传给分镜生成，避免只靠转写文本猜接法。

项目栏的“全课电路画面”一次设置全部共享电路素材，后续新生成素材沿用默认值。单素材仍可覆盖。回到实验室拖动实物或修改导线后，点“应用返回分镜”会先准备最新图形再返回；全部引用同一素材的镜头自动使用新快照。显式摆放的实物坐标不再因为重叠检测被自动重新排列。失败时保留编辑并提供重试，不会永久显示正在准备草图。

开关不是每张物理示意图的必选元件。新建实验、测量、器材操作电路应考虑主干开关；纯公式或关系示意可省。项目可选择按题意、保留已有接法，或为非题目工程明确补充主干闭合开关。补开关仅在单电源且有唯一电源引线的情况下自动进行；存在歧义时在实验室指定。题目始终保留原接法和开关状态，不能为美化擅自补开关。

公式区使用本地MathLive可视化输入，支持直接键入与分式、上下标、根号等结构模板；保存为LaTeX，仍可打开高级源码编辑。字体和组件随应用打包，无需CDN。

黑板内容用独立板书对象录入，分类为关键词、定律、题干、已知条件、推导。镜头摘要、审核提示、配音分析和公式制作备注默认不上屏。题目图片独立显示，不将解析答案自动写上黑板。普通旁白仍出现在字幕区。

“关键词高亮”可指向本镜头板书中的文字或公式中的LaTeX项，指定第几次出现、效果、颜色，以及对应台词关键词。必须先显示目标再触发高亮；时间使用真实配音事件。正文颜色为#333333，强调依次为#4F80FF、#FF6600、#16C863、#FF4D4D。标题为自适应蓝色标题条与用户提供的黄色图钉，标题只写知识点总览。

这些素材支持初中电学的知识讲解与题目讲解，包括电路、电流电压电阻、欧姆定律、电功电功率、电热、安全用电和电与磁。数值电路验证仍限于当前求解器支持的直流稳态模型；电磁感应、交流或非纯电阻的能量转换应用题可用图、板书与公式讲解，不能把电阻模型的结果当成相应仿真。

## 同源画面舞台、内置字体与固定角色

本节说明当前画面工作台的使用方式。分镜页的“画面布局”以1920×1080设计坐标工作：文字、公式、电路与题图由成片使用的Manim对象生成SVG，网页显示这些对象。画面阶段用于检查对象何时出现；精确到秒的动画与配音节奏仍在单镜头视频中验收。

在“画面阶段”选择开场、某一步板书、公式或强调，再选择当前可见元素。可以直接拖动，也可以填写X、Y和缩放倍数；X、Y以设计画面左上角为原点，向右、向下增加。方向键移动1 px，Shift加方向键移动10 px。缩放以元素左上角定位，避免缩放后位置跳动。“撤销”“此元素恢复默认”“整页恢复默认”分别用于回退本次布局、恢复一个对象、恢复当前镜头全部对象。调整会写入该镜头工程；保存并重新确认分镜后，再制作预览或成片。

“页面板式”提供自动、讲解、总结三种选择。“查看板式参考”展示参考图。讲解板式突出板书和电路；进入讲稿标注的总结/回顾部分，或分镜标题标明总结时，自动使用总结笔记底板，并延续到该总结部分的后续镜头。旧工程中的题目板式按讲解板式显示。切换板式会重置本镜头的手动位置，可用撤销回退。

总结页顶部标题保留在标题栏，板书、知识卡、公式、电路、强调动画与字幕只能出现在白色框内。拖动、键盘微调、数值定位和缩放均受这个区域限制，旧工程中越界的元素在预览和渲染时也会收回框内。内容较多时应拆成多个总结镜头，避免拥挤。

整片预览和高清成片进入总结部分前，默认插入“物理总结通用过度0721”转场（素材位于 `public/video/templates/summary-transition.mp4`，约 4.92 秒，输出时按帧率对齐）。连续总结镜头之间不重复插入；转场保留素材音效，后续旁白、字幕与成片总时长同步顺延。单镜头预览只展示该镜头，工程 ZIP 包含默认转场素材。

正文按42设计像素、56像素真实基线间距排版。内容过多时会换行并给出默认区域、教学安全区或画面边界提示；需要拆段、分镜、移动或手动缩放时，先处理提示再确认。字幕超过两行也会提示缩短字幕分段。舞台更新失败时会保留当前编辑并显示“重试舞台预览”；应等画面与最新内容同步后，再核对位置。

当前字体从项目的`public/video/fonts`加载：中文使用方正兰亭圆简体，西文使用STIX Two Text及其斜体，公式使用STIX Two Math，并支持公式中的中文。原始TTF/OTF和网页WOFF2均内置；浏览器无需字体CDN，Manim按工程路径注册到本次渲染进程，不要求全局安装字体。公式编译需要已有XeLaTeX、unicode-math、xeCJK和dvisvgm环境。

所提供的`模版5最新字体包.rar`中没有真实“方正兰亭圆简体-中粗”文件，本机字体目录中也未找到该字重。当前标题使用常规字体合成600字重，不能将它当作真实中粗；`public/video/fonts/manifest.json`明确记录`syntheticTitle: true`及实际400字重。标题按所选参考板式的字号与比例呈现。拿到中粗原文件后，应更新字体清单和模板并重新渲染，原始常规字体无需替换。

“文稿 → 配音服务与角色”集中显示固定双人配置。方大招负责解释概念、纠正错误、引导思考，语气沉稳、自信；金天练负责简短提问、试错和提出易错猜想，知识讲解占比不超过20%。双方互称使用全名。固定音色显示为只读；选择Edge、Fish.audio或Azure服务时使用对应角色音色。导入旧稿中的角色或台词问题进入审核提示，原稿与配音发音配置分别保存。学生的错误猜想保留为教学环节，并关联后续纠正步骤。

“板书与高亮”中的强调可选择圆角框选、圆角底色、下划线，并指定颜色、对象内关键词、第几次出现、同步旁白及关键词。默认持续3秒，可在“强调持续 / 秒”修改；旧工程未填写时也按3秒处理。高亮从真实配音关键词加偏移时刻开始，到指定时长后消失；超过镜头末帧的部分在镜头结束时截断，不改变同步点或镜头长度。无配音时间轴的编辑阶段只在对应强调阶段展示有限高亮，不能把阶段切换当成已验证的秒级播放。

跨电脑复制时，应保留工程内的字体与板式素材目录，以及Manim场景模块。独立字体工具在`video-renderer/fonts.py`：`register_video_fonts()`负责本地注册，`mixed_text()`负责中西文混排，`place_text_baseline()`用于真实基线定位，`glyphs_for_range()`按原文字符区间定位高亮，`stix_tex_template()`供公式编译。正文与MathTex的内部字号换算不同，使用各自的`design_font_size()`和`design_math_font_size()`，避免公式尺寸偏小。字体清单、实际family/PostScript名称和详细复制方法见`public/video/fonts/README.md`。
