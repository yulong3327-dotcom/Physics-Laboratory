## 接入方法

将收到的 MP3 放入 public/voice/curriculum/，执行 npm run prepare:audio。脚本会检查文件头、更新 src/curriculumVoice.json 中的 audio 路径，并重新生成本文档。构建时也会自动执行。新弹窗出现时自动播放对应录音；切换题型、重启或关闭引导会中止旧录音与待播队列。

物理条件已修订：等大成像对应 u = 2f；“无法成像”改为排查移动光屏；动态成像、水透镜口诀均限定仍成实像的条件；遮挡只讨论部分遮挡；焦点处单独列为边界情况。
