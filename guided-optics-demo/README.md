# 凸透镜教材实验

面向手机横屏的引导式实验，复用自由光学实验室的薄透镜近轴追迹引擎。课程依照提供的指导语，包含 15 个题型分组、25 个操作小节，题型选择器和“更多”面板均支持自由跳转。每小节先操作、再观察，最后选择或填空；操作到位与答对后会高亮下一步。

顺序为：平行光测焦距、物距像距图像测焦距、三心同高、F 光源、成像特点与应用、实像与虚像、动态成像、更多探究、透镜遮挡、眼镜判断、水透镜、无法成像、蜡烛燃烧、像物互换、结语与五组规律表。

实验支持拖动器材、滑杆调节和放大实验台。眼镜以两枚有间距的薄透镜计算，水透镜以可变焦距计算；部分遮挡通过光阑截断光线，并降低完整像的亮度；燃烧、偏心与反向传播使用实际光线计算。光屏模糊与亮度是示意近似，不模拟衍射、像差或绝对照度。燃烧由“继续燃烧”推进，以便课堂暂停与比较。

## 界面与字体

界面按 APP 参考图统一为紫色外框、圆润白色实验区、胶囊选择与按钮，以及青色观察区。手机横屏的 IP 提示条保持 42 px，主要操作按钮至少 42 px；器材可直接拖动，也可使用滑杆及 0.1 cm 微调按钮，实验台可单独放大。

正文使用提供的方正兰亭圆，标题使用阿里妈妈数黑体，数值与公式使用 STIX。发布包仅包含按课程用字裁剪的 WOFF2，合计约 347 KB；字体由站点本地加载。增改文案后，可安装 `fonttools` 与 `brotli`，再执行 `python scripts/subset-fonts.py <原字体目录>` 重新生成子集。

## 音频

IP 对话气泡随步骤出现，已有匹配录音自动播放，不显示播放按钮。更多选项提供重播、静音和关闭。55 句主线保留固定编号 001–055，7 段沿用旧录音，适用的旧版纠错、观察和表格提示也继续使用。待补录内容仅显示文字。

[AUDIO_SCRIPT.md](AUDIO_SCRIPT.md) 列出每个编号的弹窗文案、计划台词、录音状态及旧录音实际台词。收到 MP3 后放入 `public/voice/curriculum/`，执行 `npm run prepare:audio` 即可接入；构建时也会执行。无需覆盖旧 WAV 文件。

## 运行

```sh
npm ci
npm run dev
```

本地：http://127.0.0.1:5174/ 。发布构建：`npm run build`。所有资源使用相对路径，不依赖外部字体、CDN 或 AI API。

`npm run test:e2e` 使用本机 Edge 检查完整课程路径、物理计算、先观察再答题、旧音频复用、未录音内容不请求文件、自由跳转、错误答案、保存恢复、表格导出与手机布局。先运行本地服务，再执行测试。CI 运行无需浏览器的物理测试：`npm run test:e2e -- --grep "thin-lens engine"`。

GitHub Pages 工作流将本项目构建到主站 `dist/guided-optics/`。课程状态使用 `guided-optics.curriculum.v3` 保存，保留旧版有效记录表，不沿用旧的步骤编号。
