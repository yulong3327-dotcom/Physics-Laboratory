# 凸透镜成像规律 · 教材实验演示

独立的、无需登录或 AI 密钥的引导式光学实验网站。当前课程覆盖凸透镜成像规律，复用原自由光学实验室的理想薄透镜近轴追迹引擎。实验按顺序锁定：摆放器材、调节三心同高、测量焦距，再依次完成五组物距下的成像观察，最后填写规律表。

学生可以拖动器材或使用滑杆；光线、光屏光斑和烛焰像随位置实时更新。每次必须先确认物距、移动光屏，观察结果后再主动进入判断题。判断题位于侧栏，不遮挡光路。焦点处与焦点内需扫描近、远光屏位置，焦点内还需移开光屏并透过透镜观察。完成操作与判断后才解锁下一步。浏览器自动保存步骤与器材位置，最终表格可以导出 CSV 或打印。

演示采用常见初中教材顺序，尚未绑定具体教材版本。光线与像距由几何光学引擎计算；光屏模糊度是基于离焦量的可视化近似，不模拟真实相机成像、衍射或照度。

```sh
npm install
npm run dev
```

访问 http://127.0.0.1:5174/ 。生产构建运行 `npm run build`。此项目与 `circuit-converter` 自由光学实验室互不影响；后续课程可以在同一框架内扩展。

## 验证与发布

`npm run test:e2e` 使用本机 Edge 验证物理计算、完整学生路径、先观察再判断、错误拦截、刷新恢复、CSV 下载与手机布局。CI 运行不需要浏览器的物理模型测试：`npm run test:e2e -- --grep "thin-lens engine"`。

GitHub Pages 主工作流同时构建本项目，将产物放入 `dist/guided-optics/`，访问 `/Physics-Laboratory/guided-optics/`。构建使用相对资源路径，不依赖外部字体或 CDN。
